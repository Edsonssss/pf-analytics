# Аналитика портфеля: 25 бумаг + IMOEX

Технический анализ по каждой позиции портфеля и сводные рекомендации.
Данные торгов — **16.10.2026** (основная сессия Мосбиржи), отчёт сформирован **18.10.2026**.

**Открыть сайт:** `index.html` (или GitHub Pages, если включён).

## Что здесь

| Файл | Содержимое |
|---|---|
| `index.html` | оглавление: карточки всех 25 бумаг с вердиктом, скором и дивдоходностью |
| `summary.html` | **сводная**: таблица по всем акциям (S1/R1, скор, RSI, дивдох, потенциал к цели, рекомендация) + блок по IMOEX + план на неделю + дивиденды + фонды + риски |
| `imoex.html` | полный теханализ индекса МосБиржи: дневка, неделька, RSI, MACD, профиль объёма, уровни, 4 сетапа заявок |
| `IMOEX_technical_analysis_2026-10-18.html` | расширенная версия отчёта по индексу |
| `SBER.html`, `YDEX.html`, `T.html`, … `MTLRP.html` | по одной странице на каждую из 25 бумаг |
| `portfolio.html` | снимок страницы портфеля-источника |
| `style.css` | общие стили (страницы самодостаточны и без него) |
| `README.txt` | методика расчёта и инструкция по обновлению |

Каждая страница бумаги содержит: карточку позиции → рекомендацию с обоснованием → дневной график
за 130 сессий с зонами поддержек/сопротивлений, SMA20/50/200 и объёмом + RSI → таблицы уровней
(свинги, средние, Ишимоку, пивоты, Фибоначчи, узлы профиля объёма) → 13 индикаторов →
план заявок (3 очереди лимиток, стоп, цели T1/T2/T3, R/R, объём в штуках и лотах) →
события, дивиденды, цели аналитиков, риски.

## Методика

Источник цен и объёмов — [ISS Московской биржи](https://iss.moex.com/iss/), дневные свечи в режиме TQBR,
455 сессий с 03.01.2025 по 16.10.2026 по каждой бумаге + индекс IMOEX.

Индикаторы рассчитаны самостоятельно: SMA/EMA, RSI(14) по Уайлдеру, MACD(12,26,9),
Боллинджер(20, 2σ), ATR(14), Stochastic(14,3,3), Ишимоку(9/26/52), классические пивот-уровни,
профиль объёма (120 сессий), фрактальные свинги, коррекции Фибоначчи по 52-недельному диапазону.

Уровни — это зоны, а не точки: близкие свечи, скользящие средние, линии Ишимоку, пивоты, уровни
Фибоначчи и узлы профиля объёма объединяются в кластер; колонка «сигналов» показывает, сколько
независимых сигналов сошлось в зоне.

Для `T` (Т-Технологии) применена ретроактивная коррекция сплита 1:10 от 17.04.2026 — иначе
годовая статистика и скользящие средние считались бы неверно.

**Технический скор** = тренд (0…5) × 2 + моментум (−1…+4) + позиция в годовом диапазоне (−1…+1);
диапазон от −10 (глубоко медвежья картина) до +13 (сильный тренд).

## Важные оговорки

- Цены в отчёте — биржевое закрытие основной сессии 16.10.2026. На странице портфеля часть цен снята
  раньше, поэтому расхождения ±1–2% нормальны (например, PMSB: 434,2 ₽ в портфеле против 459,8 ₽ на бирже).
- Целевые цены и дивиденды взяты из портфеля (оценки Т-Банка) и открытых источников
  (БКС, Финам, Альфа-Инвестиции, Интерфакс, РБК). Взгляды аналитиков расходятся:
  по SBER цель 320 ₽ у БКС против 388 ₽ у Т-Инвестиций.
- Все графики встроены в HTML как inline-SVG: сайт работает офлайн, без внешних зависимостей.

## Дисклеймер

Материал носит исключительно информационно-аналитический характер и **не является индивидуальной
инвестиционной рекомендацией**. Технические уровни вероятностны: цена может проходить их на 1–2%
«шумом», поэтому стопы привязаны к закрытию дня. Операции с фьючерсами и инструментами с плечом
могут привести к потере всего капитала.
